# Putaran Ajaib Sifat

Permainan web pembelajaran bertema kemasyarakatan dengan suasana misteri: **Malam Misteri di Taman Harmoni** (kampung waktu malam dengan bulan, tanglung, kabus, kelip-kelip, kelawar dan kucing hitam).

- Murid tekan **PUSING!** untuk memusing roda. Kad keluar mengikut turutan tetap: 1. Rajin, 2. Jujur, 3. Malas, 4. Penakut, 5. Prihatin. Selepas kelima-lima kad, pusingan baharu bermula semula dari Rajin.
- Bila roda berhenti, kad bergambar terus timbul: **Rajin**, **Jujur**, **Malas**, **Penakut** atau **Prihatin**.
- Selepas kad terbalik, timbul arahan: **"Cuba bina ayat dan lakonkan dalam kotak lakonan!"**
- Kad dipin pada **Papan Kenyataan**. Kumpul kelima-lima kad untuk skrin tahniah.
- Ada kesan bunyi (boleh disenyapkan).
- Paparan berbentuk slaid **16:9** yang menyesuaikan saiz skrin secara automatik, dengan butang **Skrin Penuh** untuk projektor.

## Cara guna

Buka `index.html` dalam pelayar web (Chrome/Edge disyorkan). Pastikan folder `images/` berada bersama fail tersebut.
Kemajuan murid disimpan dalam pelayar; tekan **Mula Semula** dua kali untuk set semula.

## Versi satu fail

`putaran-ajaib-sifat.html` ialah versi yang sama dengan semua gambar dimasukkan ke dalam fail itu sendiri.
Fail ini boleh dibuka terus, dihantar kepada orang lain, atau dimuat naik ke mana-mana hos laman web tanpa folder `images/`.

Nota: `images/prihatin.jpg` ialah gambar sementara. Gantikan dengan gambar kad Prihatin sebenar (nama fail sama) apabila ada.

# Putaran Ajaib Sifat

Permainan web pembelajaran bertema kemasyarakatan (Pesta Komuniti Taman Harmoni).

- Murid tekan **PUSING!** untuk memusing roda. Kad tidak berulang: setiap pusingan memberi kad yang belum keluar sehingga kelima-lima kad dapat, kemudian pusingan baharu bermula.
- Bila roda berhenti, kad bergambar terus timbul: **Jujur**, **Rajin**, **Malas**, **Penakut** atau **Sombong**.
- Selepas kad terbalik, timbul arahan: **"Cuba bina ayat dan lakonkan dalam kotak lakonan!"**
- Kad dipin pada **Papan Kenyataan**. Kumpul kelima-lima kad untuk skrin tahniah, yang ada butang **Teruskan Misi** ke slaid Canva (butang ini juga muncul di papan kenyataan).
- Ada kesan bunyi (boleh disenyapkan).

## Cara guna

Buka `index.html` dalam pelayar web (Chrome/Edge disyorkan). Pastikan folder `images/` berada bersama fail tersebut.
Kemajuan murid disimpan dalam pelayar; tekan **Mula Semula** dua kali untuk set semula.

## Versi satu fail

`putaran-ajaib-sifat.html` ialah versi yang sama dengan semua gambar dimasukkan ke dalam fail itu sendiri.
Fail ini boleh dibuka terus, dihantar kepada orang lain, atau dimuat naik ke mana-mana hos laman web tanpa folder `images/`.

# Putaran Ajaib Sifat

Permainan web pembelajaran bertema kemasyarakatan (Pesta Komuniti Taman Harmoni).

- Murid tekan **PUSING!** untuk memusing roda.
- Roda berhenti pada satu sifat dan kad bergambar diterbalikkan: **Jujur**, **Rajin**, **Malas** atau **Penakut**.
- Murid meneka sama ada sifat itu **terpuji** atau **tidak terpuji** (+10 bintang jika betul).
- Penerangan dipaparkan: maksud, contoh dalam masyarakat, kesan, cara mengatasi, peribahasa dan soalan perbincangan kelas.
- Kad dipin pada **Papan Kenyataan**. Kumpul keempat-empat kad untuk lencana **Jiran Mithali**.
- Ada kesan bunyi (boleh disenyapkan) dan butang **Dengar penerangan** (suara pelayar).

## Cara guna

Buka `index.html` dalam pelayar web (Chrome/Edge disyorkan). Pastikan folder `images/` berada bersama fail tersebut.
Kemajuan murid disimpan dalam pelayar; tekan **Mula Semula** dua kali untuk set semula.
